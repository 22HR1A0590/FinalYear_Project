Privacy-Preserving Keyword Search With Access Control for Secret Sharing-Based Data Outsourcing

In today’s data-driven digital environment, ensuring the privacy and security of outsourced data is a critical challenge, especially in cloud-based services. This system enables secure data retrieval without exposing sensitive information to untrusted servers using a (k, n) threshold secret sharing scheme.

It uses a model with Data Owners, Data Users, and distributed computing servers. Data is split into shares to ensure that no partial data is ever exposed unless a minimum number of shares is combined. Users search using encrypted keywords, and servers respond without learning the queries. The framework also integrates access control using keyword and password combinations.

This efficient, scalable approach improves security while reducing overhead. Even with semi-honest servers, data confidentiality is maintained. It also prevents unauthorized searches and guards against keyword-guessing attacks.
